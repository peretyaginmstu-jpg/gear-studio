# Зацепление · Gear Studio

Версия приложения: **0.18.0**. Браузерный конструктор зубчатых колёс с двумя равноправными путями: восстановить параметры по фото с проверкой пользователем или задать их вручную. Сайт работает на русском языке; фотографии обрабатываются в браузере и не загружаются на сервер.

Сайт: https://peretyaginmstu-jpg.github.io/gear-studio/

## Что добавлено в 0.18.0

Фото-помощник может условно вывести модуль для внешнего прямозубого циклоидального колеса по `m = da / (z + 2)`. Для этого пользователь должен подтвердить тип и профиль, полное число зубьев `z`, диаметр окружности вершин `da` и высоту головки `ha = m` без укорочения. Если условия не подтверждены, помощник задаёт конкретные вопросы и оставляет модуль для ручного ввода. Результат не округляется до стандартного ряда; радиус производящей окружности и совместимость с парным колесом по фото не определяются. Исходные подтверждения, интервал PhotoScale и последующие ручные изменения сохраняются в паспорте STL и задании печати. [Формула и область применения](docs/geometry.md) · [Переходы фото-черновика и проверки](docs/photo-draft-qa.md).

## Путь пользователя

Главная предлагает выбрать фото или ручной ввод. Пользователь задаёт или подтверждает исходные данные, явно строит модель, проверяет её в 3D и подтверждает форму перед выбором STL или подготовки к печати. Переходы сами по себе не создают и не подтверждают модель. Оплата и отправка заказа пока не подключены. [Контракт пути и состояния](docs/user-journey.md).

## Возможности

- Наружные прямозубые, косозубые и шевронные колёса с аналитическими профилями и скруглениями от производящей рейки.
- Внутреннее прямозубое колесо с расчётной переходной кривой по заданному эвольвентному долбяку; внутреннее косозубое — отдельная модель без производящей переходной поверхности.
- Прямые и косозубые рейки, отдельный ZA-червяк с 1–8 заходами и правым или левым направлением, внешнее циклоидальное прямозубое колесо и прямозубое коническое колесо со сферической эвольвентой.
- Проверка цилиндрических эвольвентных пар и отдельные условные предпроверки конических и циклоидальных пар. Они показывают перечисленные геометрические условия, но не сертифицируют контакт, монтаж, ресурс или прочность.
- Анализ силуэта фото предлагает гипотезы, а не автоматически подтверждённый тип. Пользователь может уточнить направление зубьев, число, масштаб и профиль; при недостатке данных помощник показывает, что измерить или проверить. Поддержаны область анализа, PhotoScale и измерения общей нормали в применимых режимах.
- Бесплатные Standard STL и Pro STL с паспортом доступны в раннем доступе. STL проверяется на замкнутость, ориентацию, вырожденные грани и положительный объём; единицы STL не хранит — при импорте задавайте миллиметры.
- Подготовка к FDM включает геометрическую оценку параметров печати и скачиваемое JSON-задание. Это не автоматический заказ и не гарантия прочности или посадки.

## Ограничения

Октойдные и спиральные конические колёса, гипоидные и червячные колёса, цевочные, ременные и цепные передачи пока не имеют рабочего генератора STL. Фотоалгоритм проверен на синтетических сценариях; точность на реальных фотографиях ещё не измерена. Он не определяет стандарт, угол профиля, модификации или материал. Геометрические допуски сетки относятся к описанным в документации поверхностям и дискретизации; сайт не подтверждает класс точности изготовленной детали или её пригодность под нагрузкой. [Геометрия и технические границы](docs/geometry.md).

## Локальный запуск и проверки

Нужны Node.js **22.13 или новее** и npm:

```sh
npm ci
npm run dev
```

Проверки: `npm test`, `npm run check`, `npm run lint`. Production-сборка GitHub Pages:

```sh
NEXT_PUBLIC_BASE_PATH=/gear-studio npm run build:pages
```

Статический сайт собирается в `out/`. GitHub Actions запускает тесты и сборку при Pull Request; изменения ветки `main` после успешной проверки публикуются в GitHub Pages. См. [файлы и печать](docs/product-packages.md) и [QA-отчёты](docs/photo-draft-qa.md), [предпроверки пар](docs/cycloidal-pair-qa.md).
