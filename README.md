# Зацепление · Gear Studio

Браузерный конструктор зубчатых колёс. Русский интерфейс, эвольвентные и циклоидальные профили, 3D-просмотр, анализ силуэта фото, экспертные вопросы, STL и геометрическая оценка FDM-печати. Фотографии не отправляются на сервер.

Сайт: https://peretyaginmstu-jpg.github.io/gear-studio/

## Запуск

Node.js 22.18+ и npm. `npm ci`, затем `npm run dev`. Проверки: `npm test` и `npm run check`. Статическая сборка для GitHub Pages: `NEXT_PUBLIC_BASE_PATH=/gear-studio npm run build:pages`; результат в `out/`.

GitHub Actions проверяет математику и распознавание, собирает сайт и публикует изменения ветки `main` в GitHub Pages. Pull request выполняет проверки без публикации.

## Версия 0.4

- Наружные прямозубые, косозубые и шевронные колёса: аналитические боковины и огибающая скругленной производящей рейки.
- Внутренние прямозубое и косозубое колёса с ограниченной областью параметров; корни без огибающей долбяка.
- Прямая и косозубая рейки с острыми углами у корня; косозубая имеет линейный осевой сдвиг.
- Отдельный ZA-червяк: осевая трапеция, 1–8 заходов, правая/левая винтовая линия, сквозное отверстие. Без сопряжённого червячного колеса.
- Циклоидальное цилиндрическое колесо: эпициклоида головки и гипоциклоида ножки, отдельный производящий радиус, проверка достижимости впадины и пересечения зубьев. Это не цевочный редуктор.
- Коническое прямозубое колесо: точная сферическая эвольвента, два числа зубьев и угол осей, внешний модуль и ширина по образующей. Рабочие торцы по задним конусам, плоский корпус и цилиндрическое отверстие; поддержана область впадины не ниже основного конуса, без производящей галтели.
- Проверка эвольвентной пары: рабочее межосевое расстояние, геометрические зазоры, перекрытие, согласование углов и направления зубьев; отдельный отчёт JSON с обеими деталями. Конические, червячные и циклоидальные пары не рассчитываются.
- Параметры: модуль, число зубьев, угол профиля/наклона, смещение, ширина, отверстие, нормальное уменьшение толщины зуба, радиус инструмента.
- Фото: сегментация, радиальный контур и подсчёт зубьев с проверками качества. Физический масштаб и модуль требуют измерения и подтверждений. Обратный расчёт для семи цилиндрических/реечных семейств учитывает наклон, смещение и метод измерения; неизвестные параметры не подставляются автоматически.
- PhotoScale: масштаб по двум точкам эталонного отрезка и диаметр окружности по трём вершинам зубьев. Условный интервал учитывает заданную ошибку выбора точек и введённый допуск эталона; перспектива и дисторсия в него не входят. Разметка, подтверждения и происхождение измерения сохраняются в паспорте модели.
- STL проходит проверку замкнутости, ориентации, вырожденных граней и положительного объёма. STL не хранит единицы: импортировать как мм.
- FDM: габариты, вершина зуба, обод, сопло, ширина линии и слой; скачиваемое задание исполнителю. Это не автоматический заказ и не гарантия прочности.

## Границы

Октойдные и спиральные конические колёса, гипоидные и червячные колёса, эксцентриковые цевочные, ременные и цепные семейства пока представлены инженерными вопросами, без рабочего STL. Неподдержанное подрезание блокируется. Допуск эвольвентного профиля — выборочная оценка 2D-дискретизации. Для циклоидальных кривых применяется аналитическая верхняя граница ошибки плоской хорды до Float32. Для сферической эвольвенты и конических торцов ограничивается дискретизация аналитических поверхностей до Float32. Граница по основному конусу ограничивает реализованную модель и сама по себе не доказывает подрезание. Ни один режим не подтверждает класс точности готового колеса или общий 3D-допуск STL. Отдельная проверка пары оценивает перечисленные в отчёте геометрические условия, но не сертифицирует все виды интерференции, ресурс или изготовление.

Фотоалгоритм испытан на синтетических сценариях; точность на реальных фотографиях ещё не измерена. Он не распознаёт стандарт, угол давления, модификации и материал.

## Проверка и дальнейшие работы

См. `docs/geometry.md`, [сферическая эвольвента конического колеса](docs/bevel-geometry.md), `docs/photo-analysis.md`, [масштаб и измерение по фото](docs/photo-scale.md), `docs/pair-analysis.md`. Следующие приоритеты: производящая переходная поверхность конического зуба ниже основного конуса и анализ конической пары; метрологическая проверка на реальных фотографиях и полная калибровка камеры; расширение проверки пары на циклоидальное и червячное зацепление; перенос внутреннего производящего профиля и сопряжённого червячного колеса из прежнего Python-ядра; серверный CAD/STEP (потребует отдельного хостинга, GitHub Pages исполняет только клиентский код).

Паспорт модели и задание печати используют схемы v4. Циклоидальные и конические размеры и диагностика сохраняются отдельно; для конического колеса также записываются пространственные торцы и преобразование координат. В оценке FDM используются малый торец и фактическая высота. Для циклоиды постоянный угол давления и основная окружность неприменимы и имеют значение `null`. Результат проверки пары не добавляется в паспорт без отдельного подтверждённого состояния.
