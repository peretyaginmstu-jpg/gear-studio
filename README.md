# Зацепление · Gear Studio

Версия приложения: **0.27.0**. Браузерный конструктор зубчатых колёс с двумя равноправными путями: восстановить параметры по фото с проверкой пользователем или задать их вручную. Сайт работает на русском языке; фотографии обрабатываются в браузере и не загружаются на сервер.

Сайт: https://peretyaginmstu-jpg.github.io/gear-studio/

## Что добавлено в 0.27.0

Инструменты мастерской: шпоночный паз по ГОСТ 23360 и ступица, настраиваемый исходный контур (ha*, c*), размер по роликам с обратным расчётом смещения, дюймовый шаг DP, контур DXF для резки, шаблоны типовых деталей, подбор пары по передаточному числу и межосевому, напоминание о резервной копии. [Инструменты](docs/workshop-tools.md).

Связка с Layers: заказ печати из оформления, статус заказа в проекте, импорт измерений студии, повтор заказа, ревизия модели из админки студии, материалы с поправками для печатных шестерён, вход через аккаунт Layers и облачные копии проектов. [Связка](docs/layers-integration.md) · [QA выпуска](docs/workshop-tools-qa.md).

Проверки параметров идут в Web Worker, 3D-просмотр не пересоздаётся при смене вида; удалены неиспользуемые зависимости; в CI добавлены браузерные тесты.

## Протоколы образцов из 0.26.0

Протоколы измерений изготовленного образца для фото- и ручного проекта. Каждый отсчёт сравнивается с сохранёнными предельными размерами; среднее не скрывает выход отдельных значений. При известной расширенной неопределённости U сравнивается интервал, при неизвестной — только число. Автоматической приёмки детали нет.

Протокол хранит исходную модель и требования, включается в историю проекта, PDF, паспорт и задание FDM. Старые результаты не пересчитываются по новым пределам. Зафиксированную запись можно исправить через отдельную копию; исходная остаётся. Новый проект использует v5 и читает v1–v4, паспорт и задание печати — v8. [Проверка образца](docs/sample-inspection.md) · [QA](docs/sample-inspection-qa.md).

## Требования мастерской из 0.25.0

Карточка требований мастерской: назначение, количество, материал, способ изготовления, условия работы, ответная деталь и предельные размеры. Она сохраняется в проекте и истории, входит в PDF, паспорт и задание FDM. Отметка проверки привязана к параметрам и версии приложения: после изменения модели или требований нужна новая сверка. Отклонения задаются пользователем в мм; номинальная геометрия STL не меняется.

Требования не означают согласование исполнителем. Различия с материалом/процессом пробной FDM-печати показываются отдельно. Старые проекты v1–v3 читаются; новый формат — v4. [Контракт карточки](docs/manufacturing.md) · [Проверки](docs/manufacturing-qa.md).

## Размерные листы из 0.24.0

Размерный лист PDF и комплект ZIP для Standard и Pro. Три проекции и габариты строятся непосредственно из готового STL; номинальные параметры и условия показаны отдельно. Название проекта, версия и SHA-256 связывают документы с конкретным файлом. ZIP содержит тот же STL, его JSON-паспорт, PDF, манифест и памятку. Генерация работает в фоне и допускает отмену; файлы доступны для фото- и ручного пути.

Размерный лист предназначен для проверки и согласования модели. Полноценный рабочий чертёж с посадками, материалом и допусками остаётся отдельным этапом. Документы бесплатны; оплата и заказ не подключены. [Состав и геометрический контракт](docs/model-documents.md) · [Проверки](docs/model-documents-qa.md).

## Архив из 0.23.0

Архив проектов мастерской: отдельные списки «В работе» и «Архив» с поиском и счётчиками. Завершённую деталь можно убрать из рабочего списка, открыть в архиве, скачать её файл и вернуть к редактированию. Фото, параметры и история версий сохраняются. Архивирование не освобождает место на устройстве и не заменяет резервную копию.

Архивный проект защищён от записи; другая вкладка не может незаметно перезаписать его. Переносимый формат остаётся v3, импорт создаёт рабочую копию. Локальная база обновляется до версии 2 с сохранением существующих записей; старые вкладки нужно обновить. [Поведение и совместимость](docs/project-archive.md) · [Проверки выпуска](docs/project-archive-qa.md).

## Ракурсы из 0.22.0

До четырёх дополнительных ракурсов одной детали рядом с основным снимком: назначение, заметка, увеличенный просмотр, замена и отмена удаления. Галерея общая для фото- и ручного режима, сохраняется в проекте и его версиях. В фото-помощнике ракурс можно сделать основным: прежний снимок остаётся в галерее, а измерения и подтверждения основного фото нужно пройти заново. Ошибка чтения нового файла сохраняет прежнее фото и ответы.

Формат проекта v3 объединяет одинаковые изображения в один ресурс и читает старые файлы v1/v2. В JSON-паспорт модели входят подписи и происхождение ракурсов; сами снимки переносятся в `.gear.json`. Дополнительные ракурсы помогают осмотру, автоматического восстановления 3D по нескольким видам пока нет. [Поведение и границы](docs/reference-photos.md) · [Проверки выпуска](docs/reference-photos-qa.md).

## Памятки из 0.21.0

Иллюстрированные памятки рядом с ручными параметрами и на каждом шаге фото-помощника. Схемы объясняют ракурс, направление зубьев, окружность вершин, положение эталона, шаг рейки и размеры тела. Подсказки учитывают семейство, нечётное число зубьев и текущий способ ввода. В PhotoScale добавлена схема расположения эталона на высоте торца. Просмотр памятки не меняет параметры и не подтверждает измерения. [Описание и границы](docs/measurement-guide.md) · [Проверки выпуска](docs/measurement-guide-qa.md).

## История проектов из 0.20.0

Именованные версии с заметками для ручных и фото-проектов: сохранение варианта, сравнение применимых параметров, возврат с автоматическим сохранением предыдущей работы и открытие выбранного варианта отдельным проектом. История включает фото, измерения и незавершённые ответы. Файл `.gear.json` переносит её целиком, сохраняя одинаковый PNG один раз. Добавлен поиск проектов по названию. Файлы версии 0.19.0 открываются с преобразованием в новый формат; старое приложение новый формат не читает. [Проверки истории](docs/project-versions-qa.md).

## Основа проектов из 0.19.0

Локальные проекты с автосохранением: ручные параметры, рабочее фото, принятая область анализа, ответы, незавершённая разметка масштаба и поля помощников восстанавливаются после перезагрузки. В панели проекта можно задать название, открыть другой проект, начать новый, скачать файл `.gear.json` и открыть его отдельной копией на другом устройстве. Настройки печати и ответной шестерни также входят в проект.

При восстановлении ранее построенной модели сетка создаётся заново текущим ядром и проверяется; получение файлов требует повторного подтверждения. Две вкладки не перезаписывают один проект молча: при конфликте доступна отдельная копия. Проекты остаются в IndexedDB этого браузера, поэтому скачивайте файл для резервной копии. [Формат и поведение проектов](docs/projects.md) · [Проверки выпуска](docs/projects-qa.md) · [План развития](docs/roadmap.md).

Возможности 0.18.0 сохранены: условный модуль внешнего прямозубого циклоидального колеса по подтверждённым `da`, `z` и `ha=m`, с исходными измерениями и интервалом PhotoScale в паспорте. [Геометрия и область применения](docs/geometry.md).

## Путь пользователя

Главная предлагает выбрать фото или ручной ввод. Пользователь задаёт или подтверждает исходные данные, явно строит модель, проверяет её в 3D и подтверждает форму перед выбором STL или подготовки к печати. Переходы сами по себе не создают и не подтверждают модель. Оплата и отправка заказа пока не подключены. [Контракт пути и состояния](docs/user-journey.md).

## Возможности

- Наружные прямозубые, косозубые и шевронные колёса с аналитическими профилями и скруглениями от производящей рейки.
- Внутреннее прямозубое колесо с расчётной переходной кривой по заданному эвольвентному долбяку; внутреннее косозубое — отдельная модель без производящей переходной поверхности.
- Прямые и косозубые рейки, отдельный ZA-червяк с 1–8 заходами и правым или левым направлением, внешнее циклоидальное прямозубое колесо и прямозубое коническое колесо со сферической эвольвентой.
- Проверка цилиндрических эвольвентных пар и отдельные условные предпроверки конических и циклоидальных пар. Они показывают перечисленные геометрические условия, но не сертифицируют контакт, монтаж, ресурс или прочность.
- Именованные локальные проекты и версии, сравнение вариантов, автосохранение и переносимый файл с историей, фото и измерениями.
- Анализ силуэта фото предлагает гипотезы, а не автоматически подтверждённый тип. Пользователь может уточнить направление зубьев, число, масштаб и профиль; при недостатке данных помощник показывает, что измерить или проверить. Поддержаны область анализа, PhotoScale, дополнительные ракурсы с заметками и измерения общей нормали в применимых режимах.
- Бесплатные Standard STL и Pro STL с PDF, паспортом и ZIP-комплектом доступны в раннем доступе. STL проверяется на замкнутость, ориентацию, вырожденные грани и положительный объём; единицы STL не хранит — при импорте задавайте миллиметры.
- Подготовка к FDM включает геометрическую оценку параметров печати и скачиваемое JSON-задание. Это не автоматический заказ и не гарантия прочности или посадки.

## Ограничения

Октойдные и спиральные конические колёса, гипоидные и червячные колёса, цевочные, ременные и цепные передачи пока не имеют рабочего генератора STL. Фотоалгоритм проверен на синтетических сценариях; точность на реальных фотографиях ещё не измерена. Он не определяет стандарт, угол профиля, модификации или материал. Геометрические допуски сетки относятся к описанным в документации поверхностям и дискретизации; сайт не подтверждает класс точности изготовленной детали или её пригодность под нагрузкой. [Геометрия и технические границы](docs/geometry.md).

## Локальный запуск и проверки

Нужны Node.js **22.13 или новее** и npm:

```sh
npm ci
npm run dev
```

Проверки: `npm test`, `npm run check`, `npm run lint`; браузерные — `npm run test:e2e` после сборки в `out/`. Production-сборка GitHub Pages:

```sh
NEXT_PUBLIC_BASE_PATH=/gear-studio npm run build:pages
```

Статический сайт собирается в `out/`. GitHub Actions запускает тесты, TypeScript, lint и сборку при Pull Request; изменения ветки `main` после успешной проверки публикуются в GitHub Pages. См. [файлы и печать](docs/product-packages.md) и [QA-отчёты](docs/photo-draft-qa.md), [предпроверки пар](docs/cycloidal-pair-qa.md).
