Дата: 2026-09-28. Проверки выполнены локально; публикация и GitHub Actions — отдельные шаги.

## Автоматические проверки

- `npm test`: все node-тесты проходят, включая новые `bodyFeatures`, `pinMeasurement`, `dxfExport`, `layersOrder`,
  `layersLink`, `pairSynthesis`, `templates`, `backupReminder`.
- `npm run check`, `npm run lint`: без ошибок.
- `npm run build:pages` с `NEXT_PUBLIC_BASE_PATH=/gear-studio`: статическая сборка, Web Worker проверки параметров собирается.
- `npm run test:e2e` (Playwright, Chromium 1194): ручная шестерня с пазом и ступицей → STL (заголовок и длина
  файла) и DXF; размер по роликам и применение x; DP24 ↔ модуль; файл проекта: скачать → «Новый» → открыть.
- DXF прочитан ezdxf 1.x: аудит без ошибок, 2 замкнутые полилинии и окружность, `$INSUNITS = 4`.
- Layers: `python manage.py test` — все тесты, включая `orders.tests_gear_studio` (13 сценариев).

## Сквозная проверка двух сайтов

Локальный стенд: Django (SQLite) + Next.js Layers за прокси как nginx, статическая сборка Gear Studio.
Пройдено в Chromium без ошибок консоли: переход с лендинга Layers с utm → модель → PA-CF с рекомендацией
утонения 0,15 мм → применение и перестройка → заказ в Layers с подставленным материалом → статус «Принят /
цена на согласовании» → подтверждение студией 2 400 ₽ → «к оплате 2 400 ₽» → протокол студии (импорт без
сверенных требований корректно отклонён; успешный импорт покрыт тестом) → повтор с тем же файлом и email →
открытие модели из админки, z = 31, ревизия прикреплена к тому же заказу, статус снова «Принят» → вход через
Layers, облачная копия проекта v1 → воронка (переходы, черновики, открытия, заказы, согласование, повторы,
ревизии, источник `layers-landing`).
