# Архив проектов · QA v0.23.0

## Автоматические проверки

`tests/projectStorage.test.ts` исполняет реальные функции хранилища на изолированной реализации IndexedDB в памяти — [fake-indexeddb](https://github.com/dumbmatter/fakeIndexedDB). Она нужна только тестам и не входит в браузерное приложение. Это не замена проверке настоящего браузерного хранилища.

Проверяются:

- переход базы v1 → v2 без потери содержимого, фото, истории, номера редакции и последнего открытого проекта;
- архив и возврат с побайтно неизменным `contents` и датой изменения;
- запрет автосохранения архива из устаревшего и актуального редактора, сохранение отдельной активной копии;
- отклонение устаревших действий и ровно одна успешная операция при конкурентных записи/архивировании;
- явное открытие архива без перезаписи содержимого, сохранение выбора и отсутствие переключения при изменении другой записи;
- отказ клиента базы v1 после миграции, неизменный переносимый формат v3;
- отсутствие изменения данных и выбора при повреждённой либо отсутствующей записи;
- разделение списков, поиск без учёта регистра, порядок по датам и неизменность исходного массива.

## Проверено локально в браузере

Собственный тестовый проект импортирован из v3: пять версий и два ракурса синтетического изображения. Он перенесён в архив, скачан, восстановлен после перезагрузки и возвращён в работу. В рабочем разделе архивный проект отсутствовал, в архиве находился по названию. Название и редактор были заблокированы, скачивание доступно. После возврата пять версий остались доступны.

Скачанные файлы до и после архивирования прочитаны парсером. `forms`, `journey` и `versions` совпали полностью; сохранены пять версий и оба ракурса.

Две вкладки открывали один тестовый проект. После архивирования в одной вкладке сохранение из другой завершилось сообщением об архиве; исправленная локальная запись сохранена отдельной копией. Архивный оригинал остался на месте. Отдельно проверен устаревший архивный просмотр: после возврата записи из другой вкладки показана актуальная сохранённая версия с пояснением, без повторного применения действия.

При архивировании текущего проекта фокус перешёл к баннеру «Архивный проект». При архивировании другой записи текущая деталь не переключалась; список показал результат и пустое состояние выбранного поиска.

На экране 390 × 844 px проверены список архива, поиск и возврат. Ширина документа — 390 px, доступная ширина и ширина содержимого диалога — 356 px: горизонтальной прокрутки нет. В консоли обеих проверочных вкладок не обнаружено ошибок и предупреждений.

Итог локального прогона: 319 из 319 тестов прошли, TypeScript (`npm run check`) и lint завершились без ошибок. Статическая сборка `NEXT_PUBLIC_BASE_PATH=/gear-studio npm run build:pages` успешно выполнена в отдельной временной копии, без вмешательства в работающий dev-сервер.

## Выпуск

Обязательны весь набор тестов, TypeScript, lint и отдельная статическая сборка `/gear-studio`, затем успешный GitHub Actions для текущего commit и проверка публичного интерфейса. Производственную сборку нельзя запускать в `.next` работающего dev-сервера; используется отдельная временная копия.

Граница совместимости: IndexedDB v2, переносимый файл v3. Старые вкладки следует обновить после сохранения незаписанной работы файлом. При откате необходимо сохранить reader базы v2 и защиту архива; удалять хранилище нельзя. Испытания охватывают программную сохранность проекта; изготовление детали и пригодность передачи под нагрузкой не проверялись.
