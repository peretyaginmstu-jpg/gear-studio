# Переходы фото-черновика · v0.14

## Изменение

Число зубьев меняет смысл в зависимости от детали: колесо задаёт полный круговой счёт, а рейка — число зубьев выбранного линейного участка. Поэтому при переходе между ними значение очищается. Если семейство не меняет смысл счёта, введённое число остаётся для удобства, но подтверждение снимается.

Контур фото также задаёт границу применимости гипотезы: наружный круг, внутреннее кольцо или линейная рейка. Когда выбранное семейство противоречит этой подсказке, число очищается. Семейство не блокируется автоматически: наблюдение пользователя может быть верным, но значение нужно проверить заново для выбранной детали.

Любое изменение семейства снимает подтверждение числа и сбрасывает отметку переноса гипотезы повреждённых зубьев, чтобы в новом расчёте не сохранялось старое происхождение значения.
