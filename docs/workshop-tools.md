# Инструменты мастерской · v0.27.0

## Исходный контур ha*, c*

`addendumCoefficient` (ha*, 0,5–1,5, по умолчанию 1) и `clearanceCoefficient` (c*, 0,05–0,6, по умолчанию 0,25) для
цилиндрических эвольвентных колёс и реек: `ha = m(ha* ± x)`, `hf = m(ha* + c* ∓ x)`, ориентир подрезания
`x ≥ ha* − zv·sin²α/2`. Для внутреннего прямозубого c* не применяется — впадину задаёт долбяк; ha* меняет вершины.
Нестандартный контур отмечается в допущениях модели (`NONSTANDARD_RACK`).

## Шпоночный паз и ступица

Для наружных прямозубых, косозубых и шевронных колёс: паз `b × t₂` (t₂ — от поверхности отверстия по оси паза,
как в ГОСТ 23360) и односторонняя цилиндрическая ступица `D × L` на торце +z. Кнопка подставляет паз по ГОСТ 23360-78
для диаметров 6–110 мм. Отверстие и ступица — прямые призмы; закручивается только зубчатый венец. Торцы собираются
триангуляцией кольца по углу с проверкой ориентации; тесты сверяют сумму площадей торца с площадью кольца.
Проверки: стенка до впадин и до поверхности ступицы, ширина паза ≤ 0,8 d, ступица меньше диаметра впадин.
Углы паза острые — скругления и допуски задаются в требованиях мастерской.

## Размер по роликам (M)

`lib/pinMeasurement.ts`: `inv φ = inv αt ∓ (π/z − st/d) ± dp/(z·mn·cos αn)`, `d0 = db / cos φ`,
`M = d0 ± dp` (чётное z) или `d0·cos(90°/z) ± dp`. Толщина зуба — модельная, с утонением. Рекомендуемый ролик
касается у делительной окружности и выступает за вершины на 0,05 m. Обратная задача: по измеренному M —
толщина зуба, эквивалентное смещение без утонения или утонение при текущем x (один размер их не разделяет).
Формула проверена геометрически: окружность ролика касается построенного профиля на dp/2 (внешние и внутренние
колёса). Для косозубых формула точна для шариков. Предупреждения: касание у переходной кривой, выше вершины,
ролики не выступают.

## Дюймовый шаг

Переключатель «Модуль, мм / Дюймовый DP»: `m = 25,4 / P`. Модуль, равный целому DP и не входящий в ряд ГОСТ 9563,
подписывается как «дюймовый шаг DP N». Храним всегда модуль.

## Контур DXF

AutoCAD R12, миллиметры: замкнутые POLYLINE контура и отверстия (с пазом) и окружность делительного диаметра;
торцевое сечение в средней плоскости венца, `flankSamples: 32`. Для конического колеса и червяка DXF не выдаётся.
Для косозубого это сечение, а не развёртка — для резки подходит только прямой зуб. Проверено сторонним
чтением (ezdxf: 0 ошибок аудита).

## Шаблоны и подбор пары

Девять типовых заготовок (не каталожные детали производителей). Подбор пары: модули ГОСТ 9563 (1-й и 2-й ряд),
числа зубьев под передаточное число с допуском, суммарное смещение под межосевое
`inv αw = inv αt + 2Σx·tan αn/(z1+z2)`, распределение с защитой шестерни от подрезания. Каждый кандидат
проверяется существующим расчётом пары; независимая проверка — межосевое, выведенное расчётом пары из смещений,
совпадает с заданным (±0,002 мм). «Взять» кладёт шестерню в редактор, колесо и межосевое — в «Проверить пару».

## Резервная копия

Когда в проекте есть модель или версии, а копии нет (или она старше 7 дней и проект изменился), строка проекта
напоминает скачать файл или сохранить в аккаунт Layers. Отметка хранится в браузере.

## Производительность и проверки

Ручные параметры проверяются в Web Worker с задержкой 80 мс; 3D-просмотр не пересоздаёт WebGL при смене вида и
сетки. Удалены неиспользуемые компоненты UI и 202 пакета. Браузерные тесты Playwright идут в CI
(`npm run test:e2e` на статической сборке). Фото-анализ на реальных снимках меряет `scripts/photo-benchmark.ts`
(см. `bench/photos/README.md`).
