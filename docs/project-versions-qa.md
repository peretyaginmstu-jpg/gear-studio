# История проектов · QA v0.20.0

Дата: 2026-09-28. Выпуск добавляет именованные версии и перенос истории для обеих веток. Новые математические семейства и оплата не добавлялись.

## Автоматическая проверка

`tests/projectVersions.test.ts` проверяет неизменность снимков, возврат с сохранением текущей работы и обратный возврат, пересчёт фото-модели без допуска к выдаче, дедупликацию PNG, фотографию только в старой версии, миграцию v1, отказ при повреждённых ссылках и измерениях, отсутствие вложенной истории, лимиты, создание независимого проекта и сравнение применимых параметров без округления малых изменений. Сохраняются проверки десяти семейств в `tests/project.test.ts`.

- `npm test`: 300/300 PASS, включая 14 новых проверок истории.
- `npm run check`, `npm run lint`, `git diff --check`: PASS без ошибок и предупреждений.
- `NEXT_PUBLIC_BASE_PATH=/gear-studio npm run build:pages`: PASS в изолированной копии, без перезаписи `.next` работающего dev-сервера.

## Браузерный проход

Проверено локально в Codex in-app browser:

- Автоматическое открытие проекта предыдущего выпуска из IndexedDB с сохранёнными фото, шириной 11 и отверстием 8.
- Фото-модель z=24, m=2: версия с шириной 11 и заметкой, изменение до 13, таблица 11 → 13, возврат к 11. Автоматическая версия сохранила 13 и восстановилась обратно. Получение файлов после восстановления закрыто до подтверждения.
- Ручная модель z=36, m=2,5: сохранение, изменение z на 40 с пустым модулем, возврат к построенной модели и обратный возврат к незавершённому черновику. Модуль остался пустым, построение заблокировано.
- Поиск в «Моих проектах» по слову «ручная» оставляет соответствующую запись.
- Скачанный фото-проект реально появился в загрузках. Файл прочитан через текущий парсер: v2, 65 971 байт, три версии, один PNG, ширины 11/13/11. Импорт создал отдельный проект со всей историей.
- Избранная историческая версия открылась отдельным проектом с шириной 11 и пустой историей; исходный импортированный архив остаётся отдельной записью.
- На ширине 390 px диалог имеет ширину 358 px, внутренние `scrollWidth` и `clientWidth` равны 356. Карточки, таблица и действия доступны с вертикальной прокруткой; выбранная версия открыта отдельным проектом с мобильного вида. Viewport сброшен.
- Вторая вкладка сохранила именованную версию. Устаревшая вкладка получила ошибку сохранения; её новая версия не была показана как сохранённая. В независимой новой вкладке повторно открыта запись: сохранённая версия второй вкладки на месте, неудачная версия первой отсутствует.

При проходе исправлены лишние строки червячных настроек в сравнении прямозубого колеса с ручным черновиком. Сравнение теперь учитывает применимость полей и значения по умолчанию. Длинные автоматически вложенные названия заменены названием действия и временем; прежние пользовательские записи не переименовываются.

## Границы

Это проверка сохранности и пользовательского пути, не проверка реальной детали на посадку, прочность или ресурс. Фото в тесте синтетическое. Все браузерные движки и исчерпание реальной квоты IndexedDB не прогонялись. В файле до 100 версий и 32 МиБ; история не обрезается автоматически. При лимите можно открыть выбранный вариант отдельным проектом.

## Выпуск и восстановление

Перед публикацией нужны тесты, TypeScript, lint, static build, commit/push, успешный GitHub Actions и проверка живого Pages. Схема базы IndexedDB остаётся v1, но содержимое проектов переходит на `zatseplenie.project.v2`. Старый сайт 0.19 не читает новые записи, поэтому при проблеме выпускать исправление с сохранением v2-reader; не удалять базу и не откатывать парсер до v1. Переносимые `.gear.json` остаются способом резервного восстановления.
