# Связка с Layers · v0.27.0

Layers — отдельный сайт студии 3D-печати (репозиторий `layers`). Адрес задаётся переменной репозитория
`LAYERS_URL` → `NEXT_PUBLIC_LAYERS_URL`; без неё все элементы связки скрыты. Серверная часть и контракт API — в
`INTEGRATION.md` репозитория Layers.

| Связка | В Gear Studio |
|---|---|
| Заказ | «Заказать печать в Layers» в оформлении: Standard STL + SHA-256, параметры, размеры, проект и ревизия, требования. Фото и история не передаются. Ответ — ссылка на `/order/gear#токен` |
| Статус | Карточка «Заказы в Layers»: этап, цена, оплата, срок, шаги; «Обновить» |
| Измерения | «Измерения студии → проверка образца»: протоколы студии становятся записями проверки образца против сверенных пределов (нужны заполненные и сверенные требования) |
| Повтор | «Повторить заказ»: тот же STL, прошлый материал, количество и email |
| Ревизия | Ссылка из админки Layers `#layers-draft=…` открывает модель заказа отдельным проектом; в оформлении — «Ревизия в заказ LP-…» |
| Переход | `?utm_source=layers&utm_medium=…` запоминается во вкладке и уходит в черновик как `referrer` |
| Материалы | В диалоге заказа — материалы студии с утонением зуба, мин. модулем, усадкой и температурой; «Применить утонение» возвращает к параметрам |
| Аккаунт | «Мои проекты» → «Войти через Layers»: токен возвращается во фрагменте, проверяется `state`; облачные копии проектов с защитой от перезаписи по ревизии |

Токен аккаунта хранится в `localStorage` этого браузера и отзывается кнопкой «Выйти». Черновики и статусы
доступны по непрогнозируемому токену без аккаунта; контакт клиента генератору не передаётся.
