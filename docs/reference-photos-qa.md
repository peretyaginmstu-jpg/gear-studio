# Несколько ракурсов · QA v0.22.0

Сценарии проверяются на синтетическом PNG колеса с 24 зубьями и его копиях с разными именами. Это проверка интерфейса, хранения и происхождения данных; роли «сбоку» и «посадка» в тесте не означают реальные фотографии соответствующих видов.

## Автоматические проверки

`tests/referencePhotos.test.ts` проверяет перенос основного и дополнительных снимков с общей таблицей PNG, независимость метаданных и истории, восстановление удалённых ракурсов, миграцию v2, перенос основного снимка, предел числа и размера, повторяющиеся UUID, несогласованные размеры, SVG и отсутствующие исторические ресурсы. Для обеих веток проверяются сброс выдачи при изменении ракурсов и независимый снимок метаданных в доказательствах модели без пикселей.

Итог локального прогона: 309/309 тестов, TypeScript и lint прошли. Статическая сборка с `/gear-studio` завершилась успешно. Отдельный регрессионный тест исключает ложные отличия истории из-за порядка полей JSON после импорта.

## Выпуск и восстановление

Перед публикацией выполняются полный набор тестов, TypeScript, lint и статическая сборка с `/gear-studio`. Production-сборка запускается в отдельном временном каталоге, чтобы не повредить работающий Next dev. Затем — commit/push, успешный GitHub Actions для этого commit и проверка версии/галереи в публичном Pages.

Данные содержат схему проекта v3, IndexedDB остаётся v1. Исправления и откат интерфейса должны сохранять чтение v3; удаление базы или откат reader до v2 потеряют доступ к новым проектам. Скачать `.gear.json` можно для резервного переноса. Испытаний настоящих деталей, точности распознавания на реальных фотографиях и приёмки мастерскими этот выпуск не подтверждает.
