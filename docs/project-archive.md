# Архив мастерской · v0.25.0

Архив убирает завершённые работы из рабочего списка. Он сохраняет весь проект: параметры, основное фото, дополнительные ракурсы, заметки, измерения и именованные версии. Архив не удаляет записи, не освобождает место и не является отдельной резервной копией.

## Путь пользователя

В «Моих проектах» есть списки «В работе» и «Архив» со счётчиками и поиском по названию. Рабочие проекты идут по времени изменения, архивные — по дате архивирования. Поиск действует в выбранном разделе; при переходе между разделами запрос сохраняется. «Обновить список» получает актуальное состояние из хранилища.

«В архив» действует сразу, поскольку операция обратима. Текущий проект сначала сохраняется; ошибка сохранения не позволяет архивировать его. При архивировании другой записи текущая работа и выбор проекта не меняются. Успешное действие отображается только после завершения транзакции. В библиотеке после удаления строки из текущего раздела фокус возвращается к переключателю раздела.

Архивную запись можно открыть. Баннер объясняет её состояние; редактор и действия построения заблокированы, файл проекта можно скачать. История и редактирование доступны после «Вернуть в работу». При возврате модель заново проверяется текущим ядром; выдача файлов требует повторного подтверждения. Архивное открытие не сохраняет пересчитанное состояние поверх исходной записи.

## Одновременная работа

Каждое архивирование и возвращение проверяет ожидаемый номер редакции в одной read/write-транзакции. Номер увеличивается при изменении статуса; повторная установка того же статуса с актуальным номером его не меняет. Содержимое проекта и дата изменения остаются прежними.

Запись архива через обычное автосохранение отклоняется, даже если редактор успел получить актуальный номер. В другой вкладке несохранённые данные остаются в памяти; их можно скачать или сохранить отдельной активной копией. Устаревшее действие над другой записью отклоняется, список обновляется для повторного выбора.

Если открыт архивный проект и его уже вернули в работу или изменили в другой вкладке, повторный возврат показывает актуальную сохранённую запись и сообщает об этом. Повторное действие не применяется. Это допустимо для архивного просмотра, поскольку он не содержит редактируемого локального черновика.

## Данные и совместимость

- `archivedAt` хранится в строке IndexedDB рядом с `contents`, а не внутри `ProjectDocument`.
- Переносимый формат `.gear.json` — `zatseplenie.project.v4`; читаются прежние v1/v2/v3. Файл, скачанный из архива, импортируется как отдельная активная копия вместе с требованиями мастерской, если они были сохранены. Статус библиотеки другого устройства не переносится.
- База `zatseplenie-projects` обновляется с версии 1 до 2. При обновлении не удаляются и не переписываются существующие проекты и настройки; отсутствующий `archivedAt` означает рабочий проект.
- Старые клиенты открывают базу версии 1 и после обновления получают VersionError. Это не позволяет приложению 0.22 или ранее перезаписать строку без понимания статуса архива. При несохранённых данных в старой вкладке сначала скачайте проект, затем обновите вкладку и импортируйте копию при необходимости.
- Откат UI должен сохранять открытие базы v2, чтение формата v4 и защиту архивных записей. Понижение версии базы и удаление IndexedDB для отката недопустимы.
- Библиотека читает записи курсором и удерживает только метаданные списка, не собирая все изображения всех проектов в массив `getAll`.

Изменение статуса отдельной записи не меняет последний открытый проект. Явное «Открыть» сохраняет выбор даже для архива, не записывая его содержимое. Перед запоминанием открываемый документ проходит парсер; повреждённая запись не становится выбранной и не скрывается успешным архивированием.

Реализация: `projectStorage.ts` — миграция и транзакции; `projectLibrary.ts` — отбор и порядок записей; `ProjectWorkspace` — библиотека, архивный просмотр и сохранение локального черновика. [Проверки](project-archive-qa.md).
