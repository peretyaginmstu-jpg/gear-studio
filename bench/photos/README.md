# Проверка фото-анализа на реальных снимках

Фото-алгоритм до сих пор проверен только на синтетических силуэтах. Этот стенд меряет его точность на
настоящих фотографиях деталей — пилот из `docs/roadmap.md` (10–20 деталей из 3–5 мастерских).

1. Положите снимки (`.jpg`, `.png`, `.webp`) в эту папку. Только фото, на публикацию которых есть согласие владельца.
2. Опишите каждый в `manifest.json`:

```json
[
  { "file": "mixer-z24.jpg", "teeth": 24, "type": "external_circular", "note": "торец, белый фон, телефон" },
  { "file": "ring-z60.jpg", "teeth": 60, "type": "internal_ring" }
]
```

`teeth` — полное число зубьев по детали или чертежу (включая сломанные), `type` —
`external_circular`, `internal_ring`, `linear_rack` или `undetermined`.

3. Запустите:

```sh
node --experimental-strip-types scripts/photo-benchmark.ts bench/photos --json bench/photos/report.json
```

Снимки декодируются тем же Chromium, что и в браузере, и анализируются тем же кодом, что на сайте.
Отчёт показывает точность типа, долю точного числа зубьев, долю предложенных чисел и число неверных
предложений: неверное число хуже, чем честный отказ «нужно проверить вручную».
